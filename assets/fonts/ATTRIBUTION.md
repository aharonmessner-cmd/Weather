# Bundled fonts

Both typefaces are Google Fonts, licensed under the SIL Open Font License 1.1
(see `OFL.txt` in this directory), which permits bundling and redistribution
inside an application.

## Outfit

- Source: https://fonts.google.com/specimen/Outfit
- Weights bundled: Thin (100), ExtraLight (200), Light (300), Regular (400),
  Medium (500), SemiBold (600), Bold (700)
- Used for: display type — numerals, headings, the temperature hero

## Inter

- Source: https://fonts.google.com/specimen/Inter
- Weights bundled: Light (300), Regular (400), Medium (500), SemiBold (600)
- Used for: body text, labels, secondary UI copy
